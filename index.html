HOW TO PLAY

Drag back to set angle. Charge power 0–100. Read the wind flag. Fire.

Hits dig cover and hurt HP (Bobers start at 85). Falloff at the blast edge. Creek, dust, void, methane, or acid below = out. Last beaver standing wins.

Crates drop every 3 turns. Walk onto one for gear or $BOBER. Tap SHOP mid-match to buy charges. If you are short, the shop says how many more $BOBER you need.

Ten maps: Lodge Bowl, Twin Ledges, Red Mesa, Crater Rim, Methane Shelf, Acid Vents, Ring Span, Deep Pack, Frost Pit, Dock Notch. Each bank has its own scrap. Yeet Stick stays infinite. Paid guns hit harder. Crowd control: Sap Snare, Stun Cone, Grav Lure. Tap WEAPONS to pick Lodge Mortar, Pinecone Cluster, Woodchip Mine, Corkscrew Rocket, Lodge Chaingun, Arc Zap, Ricochet Fang, Ember Cascade, or a crowd-control charge. You cannot buy a win.

Pick Easy, Normal, or Hard. Both banks start even: same HP, same $BOBER, same charges. After turn 16 — and only when three or fewer Bobers remain, whichever is later — Sudden Death raises the hazard slowly. The map reacts: the creek, acid, void, or dust climbs the banks with a rumble and a siren flash.

Link Battle: Host gets a 4-letter room code. Friend taps Join and types it. Same Wi-Fi is best. Finding each other uses a short PeerJS internet hop (STUN, then TURN if needed) — no account, no lobby. Host is Lodge, Join is Creek. Two devices. If you see ICE FAIL, retry Host / Join on the same Wi-Fi.
