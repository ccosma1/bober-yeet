# Bober Yeet

Fan game by a holder.

**Play online:** https://ccosma1.github.io/bober-yeet/

Cartoon beaver in a yellow slingshot. Yeet Bober at wood and stone. 6 levels, 3 shots, 20 seconds. Enter your name, smash the dam, climb the shared leaderboard.

No wallet. No tokens. No login. No ads.

## Local

Run `START.bat` (needs Python) and open http://127.0.0.1:8765/
